## 명령 (Concentrator → Gateway)

형식: `!{게이트웨이ID 2자}{필드1}{필드2}{필드3}{필드4}`

| 위치 | 이름 | 허용값 | 의미 |
|---|---|---|---|
| 0-1 | 게이트웨이ID | 예: g1, AL(전체) | 대상 게이트웨이 |
| 2 | 잠금 제어 | O/C | Open/Close |
| 3 | 리셋 대상 | A(전체)/I(개별) | 리더 재초기화 범위 |
| 4 | 리더 동작 | R(읽기)/A(응답) | |
